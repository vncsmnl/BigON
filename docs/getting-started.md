# Começar a usar o BigON

O BigON é uma extensão do VS Code que analisa a complexidade assintótica de código sem executá-lo.

## Preparar o projeto

Requer Node.js e npm. Na raiz do repositório, instale as dependências:

```bash
npm install
```

Compile a extensão:

```bash
npm run compile
```

Execute os testes:

```bash
npm test
```

## Executar no VS Code

Abra a raiz do projeto no VS Code e pressione `F5` para iniciar o Extension Development Host. Abra um arquivo JavaScript, TypeScript, Python, Ruby, C++, C, Go ou Java para ativar a análise em tempo real.
